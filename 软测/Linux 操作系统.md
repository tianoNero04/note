1. Linux 和 Windows 有什么区别？

> [!NOTE]-
> Linux 和 Windows 都是操作系统，但它们有一些区别。
> 
> 首先，Linux 内核是开源的，而 Windows 主要是闭源的。
> 
> 其次，在操作方式上，Linux 比较常用命令行进行系统管理，Windows 则更偏向图形界面操作，不过两者都支持图形界面和命令行。
> 
> 另外，它们的文件系统和目录结构也不同。Linux 从根目录开始组织文件，而 Windows 通常使用 C 盘、D 盘这样的盘符。
> 
> 最后，在应用场景上，Linux 广泛应用于服务器、嵌入式设备等领域，Windows 则在个人办公和桌面应用方面比较普遍。

2. Linux 的目录结构是怎样的？`/etc`、`/var`、`/home` 分别有什么作用？

> [!NOTE]-
> Linux 采用树状目录结构，所有目录都是从根目录 `/` 开始的。
> 
> 其中，`/etc` 主要存放系统和服务的配置文件，比如网络配置。
> 
> `/var` 主要存放系统运行过程中经常变化的数据，比如日志和缓存，我们测试时也经常需要查看 `/var/log` 下的日志来排查问题。
> 
> `/home` 主要存放普通用户的个人文件和配置，每个用户通常都有自己的家目录。
> 
> 除此之外，还有 `/tmp` 存放临时文件，`/usr` 存放应用程序和共享资源等。

3. Linux 文件权限 `rwx` 分别代表什么？

> [!NOTE]-
> Linux 文件权限中的 r、w、x 分别表示读、写、执行。
> 
> 权限一般分为三组，分别对应文件所有者、所属组和其他用户。
> 
> 比如 `rwxr-xr-x`，表示所有者有读写执行权限，其他两组只有读和执行权限。
> 
> 如果需要修改权限，可以使用 `chmod` 命令，比如 `chmod 755`

4. `chmod 755` 是什么意思？

> [!NOTE]-
> `chmod 755` 表示修改文件权限为 `rwxr-xr-x`。其中 7 表示所有者拥有读写执行权限，两个 5 分别表示所属组和其他用户拥有读和执行权限。
