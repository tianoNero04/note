## 2026.05.15：技术栈博弈与“新手村”回归 (变化点)
### 用户
- **思考**: 不想放弃 C++，希望在简历上更有竞争力，未来想往前端深入发展。
- **行动诉求**: 询问有什么项目能结合 C++ 和 JS（前端/Node.js），想在上班摸鱼期间自学并开发。
- **疑虑**: 觉得高阶方案（Wasm/Node-API）太难，坦诚 C++ 基础几乎为零，且没有 FFmpeg/DSP 经验。
- **决策**: 要求放弃高深框架和音视频底层，需要能落地、非“玩具”的真实项目。
### 模型
- **结论**: 纠正高阶技术栈的脱离实际，回归应届生真实基准线。
- **方案**: 提出全栈化“本地大文件分析/提取系统”。
  - **C++**: 负责底层苦力活（文件读取、正则匹配、KMP 算法），复习考研专业课核心。
  - **Node.js**: 负责中台调度，通过子进程调用 C++ 脚本。
  - **Vue 3**: 负责前端展示与流式渲染。
- **建议**: 衡量项目非“玩具”的核心是“解决真实性能痛点”，建议通过纯 JS 与 C++ 处理大体积文件的性能对比（例如 2GB 日志解析耗时对比）作为简历核心卖点。
- **变化点**: 从“冲击大厂架构师”的虚构目标回归到“补齐考研基础+解决真实工程瓶颈”的务实路径。
